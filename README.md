# Hydra kalkulačka

Jednoduchá kalkulačka pre **RAID: Shadow Legends – Hydra Clash**.

**Web:** https://darangonaut.github.io/hydra-kalkulacka/

- zadáš, koľko **Clash bodov** chceš mať (napr. `1.2B`), a kalkulačka ukáže, koľko poškodenia treba nahrať
  na prvom kľúči v každej obtiažnosti (Normal ×1, Hard ×2, Brutal ×3, Nightmare ×4),
- dá sa naplánovať poškodenie vo viacerých obtiažnostiach – ukáže zvyšok a či plán prekročí cieľ,
- pri každej obtiažnosti ukáže, koľko poškodenia treba na **najvyššiu Hydra truhlicu**
  (Grandmaster / Guardian / Knight / Warrior) a celú tabuľku truhlíc.

Násobok Clash bodov platí len pre prvý kľúč na danej obtiažnosti, ďalší kľúč na tej istej obtiažnosti dáva ×1.

Hranice truhlíc sú komunitné údaje ([ayumilove.net](https://ayumilove.net/raid-shadow-legends-hydra-clan-boss-guide/),
[hellhades.com](https://hellhades.com/hydra-clan-boss-rewards/)), nie oficiálna tabuľka Plaria.

Jeden súbor `index.html`, bez servera a bez sledovania – nastavenia si pamätá len tvoj prehliadač.
Spustiť lokálne: otvor `index.html` v prehliadači.

RAID: Shadow Legends je ochranná známka Plarium. Neoficiálna komunitná pomôcka.
